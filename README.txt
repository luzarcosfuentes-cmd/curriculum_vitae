CURRÍCULUM VITAE - GITHUB PAGES

CONTENIDO
- index.html: página principal. GitHub Pages la abrirá automáticamente.
- enviacurriculo.htm: copia con el nombre solicitado en la tarea.

CÓMO PUBLICAR
1. Descomprime curriculum_github.zip en tu computadora.
2. En GitHub crea un repositorio nuevo (por ejemplo: curriculum-vitae).
3. Entra al repositorio y selecciona Add file > Upload files.
4. Sube index.html y enviacurriculo.htm (también puedes subir README.txt).
5. Presiona Commit changes.
6. En Settings > Pages, selecciona Deploy from a branch.
7. Selecciona la rama main y la carpeta /(root), luego Save.
